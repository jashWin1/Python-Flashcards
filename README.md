# Python-Flashcards

This was a Python program I wrote that helps people review Python basics through an interactive quiz. 

The program asks for:

1. Their name
2. Questions about Data Types
3. Questions about Arithmetic Operators
4. And questions about Type Casting Functions

The program checks the user's answers and gives them another chance if they question wrong. If they didnt, they get a "score" that adds up to 15 points 

The features:

1. User input and interaction
2. keeps track of the user's score
3. Has if/else statments
4. Gives the user a second chance if they got a question wrong
5. And finally it has organized sections such as Data Types or Arithmetic Operators

What I learnt:

1. How to use if and else statments in longer Python Programs
2. How to be able to check for MULTIPLE correct answers (like upper and lowercase)
3. Keeping track of scores
4. And building interactive programs making it fun for learning
